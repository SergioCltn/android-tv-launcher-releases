# Android TV Launcher releases

Public, signed update artifacts for [`SergioCltn/android-tv-launcher`](https://github.com/SergioCltn/android-tv-launcher).

The `releases` branch is generated by GitHub Actions and contains only:

- `latest.json` — version, download URL and SHA-256 checksum.
- `tvhome.apk` — the latest production-signed launcher.

Do not add credentials or source code here.
